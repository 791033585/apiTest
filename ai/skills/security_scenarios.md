# 接口安全测试场景 Skill

## 生成前提

安全测试只能用于用户明确授权的被测环境。优先根据 OpenAPI 的 `securitySchemes`、全局 `security`、操作级 `security`、请求字段定义、响应状态码和用户补充的业务规则设计场景。

## 认证与授权

1. 接口声明需要认证时，可以生成缺失认证凭证、认证格式错误和无效凭证场景。
2. 预期 `401`、`403` 或其他状态码必须来自 OpenAPI 响应定义或用户明确提供的规则；没有依据时不得猜测。
3. 过期 Token 场景只有在用户提供过期 Token、生成方式或可引用变量时才生成。
4. 权限越权场景只有在用户提供角色、权限规则以及对应测试账号或 Token 时才生成。
5. 不得在用例中编造真实账号、密码、Token、签名或管理员身份。

## 输入安全

1. SQL 注入和 XSS 仅作为非破坏性字符串输入，用于字符串类型的查询参数、路径参数、表单字段或 JSON 字段。
2. 注入输入不得包含数据删除、数据修改、文件操作、系统命令或外部回连行为。
3. 每条安全用例只验证一个输入点，不要把多个攻击字符串堆进同一条用例。
4. 只有文档声明了错误状态码、响应字段或安全要求时，才能生成确定断言；否则在 `notes` 中说明需要人工确认预期结果。
5. 禁止输出或要求执行 Python、Shell、SQL、JavaScript 等脚本。测试载荷只能作为普通请求字符串发送。

## 敏感数据与传输

1. 如果 OpenAPI 把服务地址声明为 `http://`，可在 `notes` 中提示生产环境应使用 HTTPS，但不要伪造为可执行响应断言。
2. 密码、Token、身份证号等敏感字段是否泄露，只能在响应 schema 明确包含相关字段时设计检查；不得猜测 JSONPath。
3. 不在测试日志、标题、断言或输出文件中写入真实密钥和真实敏感数据。

## 性能边界

- 单请求响应时间只有在用户需求明确给出阈值时才生成 `response_time` 断言。
- 并发测试、容量测试和压力测试不属于当前 Pytest 功能接口用例生成范围，应交给 Locust、JMeter 等专用工具。
